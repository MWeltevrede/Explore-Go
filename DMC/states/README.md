# Installation
Follow the installation instructions at the [contextual-dmcontrol](https://github.com/MWeltevrede/contextual-dmcontrol/tree/feat/explore_go) repository then build the container:
```
apptainer build cdmc.sif recipe.def
```


# Usage
For an example of how to train and eval locally, see scripts `run_train.sh` and `run_eval.sh` respectively.
